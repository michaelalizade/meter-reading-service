# Meter Reading Service

A Spring Boot REST API for managing utility meter readings and user accounts.

## Features
- User authentication via Keycloak (JWT)
- CRUD operations for **Meters** and **Readings**
- Role-based access control
- Swagger API documentation
- PostgreSQL persistence
- Flyway for database migrations
- Unit and integration tests included

## Tech Stack
- Java 17+
- Spring Boot 3.4
- Sprint Data JPA
- PostgreSQL
- Keycloak
- Swagger / OpenAPI 3
- JUnit 5 + Mockito
- Flyway
